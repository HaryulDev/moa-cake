# 모아의 케이크 만들기

꼬마 파티시에 모아와 함께 반죽 → 붓기 → 굽기 → 크림 → 장식까지 직접 만드는 케이크 만들기 게임이에요.

- 게임 주소: https://haryuldev.github.io/moa-cake/
- 휴대폰에서는 「앱으로 설치하기」(안드로이드) 또는 공유 → 홈 화면에 추가(아이폰)로 앱처럼 설치할 수 있어요.

## 파일
- `index.html` — 게임 전체 (3D 케이크는 Three.js를 인터넷에서 불러와요)
- `manifest.webmanifest`, `icons/` — 앱 설치 정보와 아이콘
- `sw.js` — 오프라인 저장·자동 업데이트 (파일 목록을 바꾸면 `VERSION`을 올려 주세요)
- `phone-test.ps1` — 같은 와이파이의 휴대폰으로 PC에서 바로 테스트하기
